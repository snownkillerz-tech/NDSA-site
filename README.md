# Сайт партии «Наш Дом Сан-Андреас» (НДСА)

Статический сайт (HTML + CSS + JavaScript). Без backend, баз данных, API и сборки.

## Структура
```
index.html      — разметка всех разделов
styles.css      — стили, адаптивность
script.js       — меню, аккордеоны, анимации, плавная прокрутка
assets/         — логотип, фото кандидата, favicon, OG-картинка
```

## Локальный запуск
Самый простой способ — открыть `index.html` двойным кликом в Chrome, Edge или Firefox.

Или через локальный сервер (по желанию):
```
python -m http.server 8000
```
и открыть http://localhost:8000

## Публикация бесплатно

### Netlify (быстрее всего)
1. Зайти на https://app.netlify.com/drop
2. Перетащить папку `ndsa-site` целиком в окно браузера.
3. Сайт получит адрес вида `https://xxxx.netlify.app` (можно переименовать в Site settings → Change site name).

### GitHub Pages
1. Создать публичный репозиторий на GitHub (например, `ndsa`).
2. Загрузить в корень репозитория содержимое папки: `index.html`, `styles.css`, `script.js`, папку `assets`.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/ndsa/`.

### Превью ссылки в Discord
После публикации замените в `index.html` относительный путь в `og:image` на полный адрес, например:
`<meta property="og:image" content="https://<ваш-сайт>/assets/og-image.jpg">`
Discord требует абсолютную ссылку для картинки превью.
